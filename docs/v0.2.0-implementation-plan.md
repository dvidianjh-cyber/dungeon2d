# Implementation Plan - Dungeon2D v0.2.0

Upgrade Dungeon2D to version 0.2.0 by introducing Quality-of-Life (QoL) UI features, mouse-picking interactions on remote peers, glassmorphism peer modals, and a 1-on-1 private chat flyout over WebRTC.

## User Review Required

> [!IMPORTANT]
> **Key Architectural Decisions:**
> 1. **Strict Decoupling:** `RenderEngine` performs coordinate transformation (screen-to-world) and hit detection against peer AABBs, emitting `input:peer_hover`, `input:peer_unhover`, and `input:peer_click` via the Event Bus. It does not manipulate DOM elements directly.
> 2. **Modal Positioning & Lifecycle:** Hovering displays a transient glassmorphic tooltip with peer details. Clicking locks open a persistent modal card featuring a "Talk" action button and a close button. Clicking elsewhere on the canvas dismisses the pinned modal.
> 3. **Targeted WebRTC Chat:** A new `DIRECT_CHAT` message payload is handled in `WebRTCEngine`, strictly sanitized with `sanitizeString()` against XSS before rendering in the chat pane.

### Render Engine & Input Handling

#### [MODIFY] [src/render/RenderEngine.js](file:///c:/Users/dvidi/Documents/Progamming/dungeon2d/src/render/RenderEngine.js)
- Track current local player position to accurately calculate world coordinates.
- Implement `screenToWorld(screenX, screenY)`:
  - Reverses `ctx.translate(width/2, height/2)`, `ctx.scale(zoomScale, zoomScale)`, and `ctx.translate(-player.x, -player.y)`.
  - Formula: `worldX = player.x + (screenX - width / 2) / zoomScale`, `worldY = player.y + (screenY - height / 2) / zoomScale`.
- Implement `findPeerAt(worldX, worldY)`:
  - Check point intersection against cached 40x40 pixel AABB bounds (`x - 20` to `x + 20`, `y - 20` to `y + 20`) for each peer.
- Add mouse listeners on `canvas`:
  - `mousemove`: Calculate screen-to-world position, detect peer hover, emit `input:peer_hover` or `input:peer_unhover`, update canvas cursor (`pointer` vs `default`).
  - `click`: Detect clicked peer, emit `input:peer_click` or `input:canvas_click`.
