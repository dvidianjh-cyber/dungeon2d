# Town adventure implementation

1. Replace the single-room prototype with a metadata-driven world simulation, authoritative inventory/economy, collisions and declarative interactions.
2. Author Littleton and its twelve venues, residents, a lost-property quest and a linked casino pack.
3. Render original procedural pixel graphics and animated directional sprites, with a responsive adventure UI, map, journal, chat and synthesized sound.
4. Support solo play and up to eight peers through a host-authoritative PeerJS session, with late-join snapshots and connection lifecycle handling.
5. Validate and import/export custom-extension ZIP bundles. Document the schema and extension points.
6. Verify simulations, malformed inputs, contention and archive round trips with automated tests; build and exercise the browser UI and multiplayer.
