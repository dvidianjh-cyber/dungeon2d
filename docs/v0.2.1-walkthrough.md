# Walkthrough - Dungeon2D v0.2.1

Version 0.2.1 introduces a tabbed interface for the initial connection modal, chat pane layout alignments, and a proximity-based `enabledRange` interaction system:
1. **Horizontal Tab Navigation:** Two styled tabs ("Create Room" and "Join Room") at the top of the connection modal with active/inactive dark-mode visual states.
2. **Dynamic Form Fields:** The Player Handle input is shared across tabs; the Join Code input is conditionally revealed only on the "Join Room" tab.
3. **Dynamic Action Button:** A single primary button updates its label ("Create Room (Host)" vs "Join Room") and validation logic depending on the active tab.
4. **State Retention:** Player handle input persists unchanged when switching between tabs.
5. **Chat Pane Alignment:** The top of the 1-on-1 direct chat flyout is aligned directly with the bottom edge of the app title bar (`top: 60px; height: calc(100vh - 60px)`).
6. **Action Range System (`enabledRange`):**
   - Modal action buttons are governed by an `enabledRange` property (for "Talk", 100 world pixels / 1 grid square).
   - Clicking a peer from beyond 1 grid square renders the Talk button disabled (`.out-of-range`, `💬 Talk (Out of Range)`).
   - Walking within 1 grid square immediately and dynamically enables the button (`.in-range`, vibrant blue glow, `💬 Talk`).
